打开一个信息很多的页面，你会先看哪里？如果每一块内容都在强调自己，读者反而需要花时间决定从哪里开始。这篇原创示例稿尝试用一个简单方法处理这个问题：先安排关系，再安排间距。

## 先画出信息的亲疏关系

以文章卡片为例，标题与摘要属于同一个阅读单元，日期与阅读时长属于辅助信息。标题和摘要应该靠近，辅助信息则可以稍远一点。这里真正起作用的并不是某个“漂亮数值”，而是距离形成的分组。

拿纸画三个方框，把最希望读者看到的信息放在第一个框。接着只问一句：移除其他两个框，它还能独立表达意思吗？如果不能，可能需要调整内容本身，而不只是调整样式。

## 用一套小尺度替代随意微调

可以先选一组间距，例如 4、8、12、16、24、32 像素。它不是永远正确的答案，而是减少犹豫的起点。

```css
.card {
  padding: 24px;
  border-radius: 24px;
}
.card h2 { margin-bottom: 12px; }
.card .metadata { margin-top: 24px; }
```

标题与摘要之间的距离，比卡片内容与边界之间的距离小，分组关系就开始变得清晰。若中文标题折成三行，应再次检查视觉重心，不能只盯着单行的示意图。

### 做一次灰度检查

暂时去掉所有强调色，把页面变成灰度。如果仍能辨认标题、正文和操作，说明层级不完全依赖颜色。再把字号缩小到手机宽度检查，看看导航是否挤压内容，按钮是否仍然容易点击。

## 给段落设一个阅读速度

中文长段落不需要追求极宽的行长。宽度过大时，眼睛换行更容易丢失位置。可以从 36 到 42 个汉字左右的正文行长开始观察，再结合字体和设备调整。

行高也不是越大越轻松：段落过松时，连续的论证容易被打散。正文可以从约 1.8 到 2 倍行高开始，标题适当收紧，段间距则负责表达新的意思。

> 留白的目标，是让信息之间的关系可以被看见。

## 一次十分钟的小练习

1. 选一个已有页面，只保留标题、摘要与一个主要操作。
2. 给信息分组，先调整组间距离，再调整组内距离。
3. 在 375 像素和桌面宽度各检查一次。
4. 用键盘依次访问操作，确认焦点没有被装饰遮挡。
5. 最后恢复颜色，避免把所有元素都染成强调色。

练习结束后，不妨保留前后两张截图，记录你为什么调整。设计判断会变化，保留推理过程比保留某个像素数更有价值。
